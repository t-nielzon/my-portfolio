Professional work

NavixScribe

The AI clinical scribe behind navix.ai. I engineered the pipeline end to end: chunked audio upload with persistence and retry, Deepgram dictation behind an ephemeral-token broker, template-driven note generation, and a LangGraph benefits-verification agent with per-case memory. A delta output contract cut form-autofill output tokens by 98%.

SmartFill

Multi-agent form autofill for the Navix Hub behavioral-health EMR, which I architected and led. An orchestrator plans field groups, runs agents in parallel over targeted chart retrieval, and merges schema-validated, PII-filtered output across OpenAI and AWS Bedrock, replacing one long serial prompt per form.

Monee AI Support

A serverless AI customer-support backend for an e-commerce payments platform, which I built as its primary engineer: Go on AWS Lambda with DynamoDB Streams and SQS, Claude on Databricks with retrieval, a policy gate on every auto-reply, and a replay harness that gates model changes.

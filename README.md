# Nielzon Tolentino - Portfolio Site

Personal portfolio of Nielzon Tolentino, a senior software engineer building LLM agents, serverless backends and AI products for healthcare and fintech.

## Technologies Used

Static HTML, CSS and JavaScript on the HTML5 UP template, deployed on Netlify with a Netlify Forms contact form. The site lives in `nielzonTolentino/`.

## Featured Work

Professional work:

* **NavixScribe**: the AI clinical scribe behind navix.ai: chunked audio pipeline, server-side dictation, LangGraph benefits-verification agent.
* **SmartFill**: multi-agent clinical form autofill for the Navix Hub EMR across OpenAI and AWS Bedrock.
* **Monee AI Support**: serverless AI customer-support backend on Go, AWS Lambda and Claude on Databricks.

Side projects:

* **Kaetram**: open-source 2D browser MMORPG.
* **Hunters NavAid Tools**: Philippine Air Force Innovation Challenge entry for coordinate conversion and mission planning.
* **Shapify**: Babylon.js sandbox for drawing 2D shapes and extruding them to 3D.
